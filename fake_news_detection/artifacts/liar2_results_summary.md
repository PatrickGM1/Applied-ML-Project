# LIAR2 Generalization Summary

## Setup

We evaluated the best project model, `binary_bert_metadata`, on the LIAR2 binary test split generated by the project LIAR2 preprocessing pipeline.

- Model: `binary_bert_metadata`
- Dataset: LIAR2
- Split: test
- Evaluated rows: 1,565
- Skipped rows: 0

## Results

| Metric | Value |
|---|---:|
| Accuracy | 0.8006 |
| Macro F1 | 0.7952 |
| Weighted F1 | 0.8029 |

Class-level performance:

| Class | Precision | Recall | F1 | Support |
|---|---:|---:|---:|---:|
| fake | 0.8798 | 0.7830 | 0.8286 | 963 |
| real | 0.7048 | 0.8289 | 0.7618 | 602 |

Confusion matrix:

```text
              predicted_fake  predicted_real
true_fake              754             209
true_real              103             499
```

## Conclusion

These are strong results. The model evaluates well on LIAR2, with accuracy above 80% and macro F1 close to 0.80. This suggests good cross-dataset generalization from the original LIAR-based training setup to the LIAR2 binary evaluation setting.

The result is especially encouraging because macro F1 is close to accuracy, meaning performance is not only driven by the larger `fake` class. However, the model is still better at identifying `fake` claims than `real` claims: `fake` has higher F1, while `real` has lower precision.

Overall, the LIAR2 evaluation supports the conclusion that the best BERT + metadata model generalizes well to a related but separate fake-news dataset, although some class imbalance and real-claim false positives remain.
